事件快照归档

AI 检测命中人形 / 车辆 / 宠物的事件快照，按 归档目录/日期/摄像头/ 结构自动复制一份到所选目录（复制不改事件库，删除事件不影响归档）。可在飞牛文件管理中直接浏览，也可在事件列表点「打开归档」跳转。

目录布局：归档目录/yyyy-MM-dd/摄像头名/时分秒-事件id-类型.jpg。仅对开启归档之后新产生的 AI 事件生效，历史事件不回溯归档。
查看入口：①「事件告警」页按类型筛出 AI 人形 / 车辆 / 宠物事件，点事件卡上的「打开归档」直达对应文件；②飞牛文件管理中直接浏览归档目录。

全部录像文件管理

跨摄像头查看 / 批量打包下载 / 批量删除。日常看某个摄像头的录像请从首页摄像头卡片 → 录像文件进入。

Home Assistant（MQTT）

一次配置，全部摄像头自动出现在 HA：每台摄像头注册 1 个画面实体 + 人形 / 车辆 / 宠物 / 画面变动 4 个传感器，自动化直接按识别结果写条件（深夜有人 → 开灯）。无需逐台直连、无需 HACS 集成、无需 Frigate。前提：HA 已装 MQTT 集成（设置 → 设备与服务 → 添加 MQTT Broker）。

高级选项

录像参数

例：设 80 表示录像分段总大小最多占所在卷容量的 80%，超出即自动删除最旧分段。与保留天数互补：天数控制「最多留多久」，水位控制「最多占多少」。

程序数据目录是应用自身的数据所在：设置项、访问密码凭据、事件库、快照索引与 AI 模型等都保存在这里，与录像文件相互独立。请勿手动删除或改动该目录，否则设置会重置、事件记录会丢失；系统升级不影响它。

运动侦测与自动录像

基于实时画面的 8×8 感知哈希帧差检测，复用兼容画面已有的解码帧，不额外占用摄像头取流通道。自动录像在检测到运动时开录、画面静止后按尾延时自动封段停录，不会影响手动录像。默认全部关闭。

在最近画面上拖拽框选不参与侦测的区域；排除区不产生事件，也不会影响自动录像之外的画面。

门禁访问密码

进入本系统所需的访问密码（独立于米家账号）。修改后需用新密码重新解锁；原“一键解锁链接”会失效。当前已登录会话不会被退出。

米家设备控制

把米家 App 里的常用摄像头设置接进本应用：经米家云 MIoT 规格读写，云端即时下发。各机型支持的属性不同，读取失败的项会标「不支持」；夜视模式的取值语义因机型略有差异（关闭 / 打开 / 自动）。

RTSP 取流

供 VLC / NVR 等外部播放器直接拉流。端口修改后自动重绑定并重连取流；令牌用于拉流地址鉴权，播放地址需带 ?t=令牌。留空不变，输入 - 清除。

HLS 预览参数

网页 HLS 实时预览的分片与预热设置。保存后立即生效：分片时长/窗口/音频会让正在进行的预览短暂中断后自动恢复；预热开关下一轮自动生效。

按设备取流清晰度 / 云台

清晰度档位在每次建立取流连接时生效，保存后会立即重建当前连接（短暂中断数秒）。「自动」按型号选择，并在设备持续不出画面时自动降级；手动固定档位后不再自动降级。云台方向键在实时预览窗口内，复用当前取流会话，不会额外占用摄像头连接。

共享看板参数

免鉴权共享大屏的事件、心跳与轮询周期。事件时长对下一次触发生效，心跳周期下一轮生效；轮询/兜底重载在大屏下次加载时生效。

本地 AI 检测

对运动侦测的事件快照做本地推理（SSD-MobileNetV1，完全离线），自动把事件细化为 AI 人形 / 车辆 / 宠物检测，事件页可按类型筛选。推理在后台单核排队执行，不影响录像。
最低配置：双核 CPU、空闲内存 1GB、数据盘剩余 300MB（单帧 1～3 秒）；推荐配置：4 核 CPU、空闲内存 2GB（单帧约 0.3～1 秒）。

备份与恢复

导出全部应用设置、共享看板与访问密码凭据（哈希，不可逆）为 JSON 文件；导入后立即生效。 导出文件包含敏感信息（RTSP 令牌、通知凭据等），请妥善保管。米家登录会话不随备份迁移（换机需重新登录米家账号）。

共享看板

配置多宫格并生成免登录共享链接，可直接配置到 Android TV 或其他浏览器长时间展示；外部事件系统可通过 Webhook 驱动画面切换。
