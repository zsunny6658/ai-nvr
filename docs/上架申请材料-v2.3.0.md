### 2. 首次上架用途说明（粘贴用）

```
aiNVR 是一款 AI 增强的摄像头网络录像服务（NVR），用于在飞牛 NAS 上接入和管理本人自有
的小米智能摄像机：通过小米私有协议直连接入，无需开启 RTSP/ONVIF、无需刷固件；提供网页
实时预览、画面变动侦测与事件告警、本地 AI 识别（人形/车辆/宠物，完全离线推理）、分段录
像与时间轴回放、标准 RTSP 下行、免登录共享大屏等 NVR 能力。录像与事件数据全部保存在
NAS 本地，不上传任何云端。软件以 GPL-2.0 开源（基于上游开源项目 i-nvr by IndSvr 二次开
发并延续同许可发行）。
```

### 3. 网络架构说明（预回应审核关注点）

```
访问架构说明：
- 桌面入口：经 fnOS 统一网关访问（Unix Domain Socket + /app/ainvr 前缀反代），
  与系统访问码体系兼容；
- service_port=9099：局域网直连入口，供 RTSP 下行（9554）、Android TV 共享大屏等
  非 HTTP 场景与局域网直接访问使用；
- 应用自带密码门禁（PBKDF2 加盐哈希 + 会话管理），免登录共享看板链接支持有效期与撤销。
```

## 二、FN软仓（社区源聚合申请）

### 1. 已完成的准备

- ✅ `fnrc.json` 已创建并入库仓库根目录（与 moo.json 并列）
- ✅ fpk 放 GitHub Release（客户端下载走内置加速器，无需处理）
- ⚠️ fnrc.json 必须经 Gitee 分发（客户端拉取不走加速，GitHub raw 会被 DNS 污染）——本仓库 Gitee 镜像正好满足

### 2. fnrc.json 的 Gitee 直链（聚合申请表单填这个）

```
https://gitee.com/sunnymore/ai-nvr/raw/master/fnrc.json
```

### 3. fnrc.json 当前内容

```json
{
  "source_name": "aiNVR 官方源",
  "apps": [
    {
      "id": "ainvr",
      "name": "aiNVR",
      "version": "2.3.0",
      "download_url": "https://github.com/zsunny6658/ai-nvr/releases/download/v2.3.0/ainvr.fpk",
      "platform": "x86"
    }
  ]
}
```

### 4. 申请步骤

1. 打开 FN软仓官方社区的**聚合申请表单**（在 club.fnnas.com 社区 FN软仓相关帖/官方群获取表单入口，客户端「设置」内也有申请通道）
2. 填入上面的 fnrc.json Gitee 直链
3. 提交后官方服务端自动解析 JSON，应用合并进官方列表，无需审核互动
4. 后续发版只需更新 fnrc.json 的 version 与 download_url（改完推 Gitee 即生效）

### 5. 版本更新操作（每次发版）

`fnrc.json` 与 `moo.json` 同步更新 version + download_url + SHA256 → commit → push Gitee（fnrc 必须）+ GitHub（fpk 资产自动就位）。
