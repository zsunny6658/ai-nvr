# aiNVR v2.3.0 —— 「监控台」界面全面升级

本次为界面大版本：默认视觉全面转向深色「监控台」风格，导航与首页信息呈现重构。功能逻辑与协议无变更，可直接覆盖升级；升级后如个别页面显示异常，请强制刷新一次浏览器缓存。

## 界面

- **深色监控台主题（默认）**：全新深色配色体系，视频画面观感更佳；「设置 → 外观」可一键切换浅色，选择记忆在本浏览器。
- **导航重构**：桌面端改为左侧导航栏（窄屏自动收窄为图标条），手机端为底部导航栏；未处理事件数以红点角标显示在「事件告警」入口上。
- **摄像头卡视频化**：卡片顶部显示最近画面快照，随运行概览每 30 秒自动刷新，点击画面直接进入实时预览；离线设备显示占位。多设备 / 弱网环境可在「设置 → 外观」关闭快照。
- **时间轴回放、共享看板、登录与锁定页**视觉同步统一；时间轴录像段 / 运动标记重新配色。
- **设置页**：开关控件改为滑动样式；新增「外观」分组（主题、摄像头卡快照）。
- **移动端与飞牛 App**：底部导航、安全区、弹层高度等适配整体重调。

## 其他

- 命令行帮助示例与环境变量命名统一（`ainvr` / `AINVR_REGION`）。
- 界面资源版本 v=54，升级后 WebView 会自动加载新样式。

## 升级说明

- 覆盖安装即可，配置与数据不受影响。
- 主题与快照开关为浏览器本地记忆，多设备各自设置。
